## Objective

Nettoyage post-migration d'activity-scraper vers stealth-fetch : supprimer les paramètres
deprecated `flaresolverr_url`, corriger les erreurs lint/type préexistantes, mettre à jour
le suivi des consommateurs, et corriger les erreurs pyright de stealth-fetch.

## Achievements

- **Suppression des paramètres `flaresolverr_url` deprecated** dans activity-scraper : retiré
  des 3 signatures (`fetcher.py`, `scraper.py`, `crawler.py`) — aucun call-site ne les passait.
- **Correction de 20 erreurs lint/type préexistantes** dans activity-scraper :
  - ruff F401 : import `unquote` inutilisé dans `wikipedia.py`
  - pyright : `selectolax.attributes.get()` retourne `str | None`, remplacé le default `""` par
    le pattern `or ""` dans `heuristic.py` et `wikipedia.py`
  - pyright : ajout de gardes `assert ... is not None` dans les tests avant `in` sur champs nullable
- **CONSUMERS.md mis à jour** : activity-scraper coché comme migré (Phase 2 complète pour ce consumer).
- **Correction de 3 erreurs pyright préexistantes** dans stealth-fetch :
  - `curlffi.py` : ajout `AsyncSession = None` dans le bloc `except ImportError` (même pattern que
    `stealth.py`), narrowing via `is None` au lieu de `_AVAILABLE`
  - `stealth.py` : narrowing `nodriver is None` au lieu de `not _AVAILABLE` pour que pyright voie
    le module comme non-None après le guard

## Decisions

1. **Pattern `is None` pour le narrowing pyright des imports optionnels**
   - **Choix** : remplacer `if not _AVAILABLE` par `if AsyncSession is None` / `if nodriver is None`
   - **Rationale** : pyright ne peut pas connecter `_AVAILABLE` (booléen) au binding de l'import ;
     le narrowing direct sur la variable importée résout le problème sans `type: ignore`
   - **Alternative rejetée** : `# type: ignore[reportPossiblyUnboundVariable]` — supprime le warning
     au lieu de le corriger structurellement
