### Cause racine des 39 bloqués
Blocage au niveau **IP reputation / CDN edge** — le VPS (IP datacenter Hostinger) reçoit un
502 avant même que la requête atteigne le serveur d'origine. Un navigateur stealth ne résout
pas le problème car le blocage se fait avant la négociation TLS.

## Décisions

1. **`min_level` comme paramètre de cascade**
   - **Choix** : ajouter `min_level` à `fetch_html()` plutôt qu'un flag `js_required`
   - **Rationale** : plus générique, permet de sauter n'importe quel sous-ensemble de moteurs.
     Un consumer qui sait que sa cible nécessite du JS passe `min_level=3` directement.

2. **Détection Chrome error pages par copyright CSS**
   - **Choix** : `"The Chromium Authors" in html[:2000]` comme marqueur unique
   - **Rationale** : Chrome utilise plusieurs messages d'erreur selon le type de panne
     ("temporarily down", "DNS address could not be found", "refused to connect") mais tous
     partagent le copyright CSS Chromium. Aucun vrai site web n'a cette chaîne dans ses
     premiers 2000 caractères.
   - **Alternative rejetée** : lister chaque message d'erreur individuellement — fragile,
     incomplet (v2 en a raté).

3. **Seuil page vide à 100 octets**
   - **Choix** : `len(html) < 100` → RuntimeError
   - **Rationale** : les pages de 39B observées sont des redirections échouées ou des rendus
     vides. Aucune page web légitime ne fait moins de 100 octets.

## Problèmes

1. **Faux positifs Chrome error pages (23 domaines)**
   - **Symptôme** : nodriver retourne ~185KB de HTML avec status 200 pour des domaines
     inaccessibles.
   - **Cause** : Chrome rend ses pages d'erreur intégrées localement et les expose via CDP
     comme du contenu normal.
   - **Solution** : détection par `"The Chromium Authors"` dans les 2000 premiers caractères
     (a28235c, 821ba55).
   - **Impact** : sans ce fix, 23 domaines auraient été faussement classés `stealth`.

2. **Pages vides 39B (7 domaines)**
   - **Symptôme** : nodriver retourne 39 octets de HTML vide avec status 200.
   - **Cause** : redirections échouées ou rendus avortés côté Chrome.
   - **Solution** : seuil `len(html) < 100` (a28235c).

3. **sciencemuseum.org.uk intermittent entre runs**
   - **Symptôme** : `direct` en v1, `stealth` en v3.
   - **Cause** : comportement réseau transitoire, pas un bug stealth-fetch.
